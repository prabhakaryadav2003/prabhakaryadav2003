## About

<table>
<tr>
<td width="62%" valign="top">

I'm a **Software Engineer** who enjoys the whole path from an idea to something running in production — designing the data model, writing the API, shipping the interface, and keeping it healthy afterwards.

Most of my work sits in the **TypeScript / React / Next.js / Node.js** world, with **Python** for data and machine-learning work. I care about clean boundaries between layers, honest error handling, and code that the next person can read without a guide.

Outside of the web stack I have a background in **electronics and embedded systems** (STM32, sensors, IoT), which still shapes how I think about constraints and reliability.

**What I'm drawn to**

- Backend architecture and API design
